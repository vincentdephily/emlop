# Emerge and portage parsing utilities

This repo contains crates that provide information about past and present
[Portage](https://wiki.gentoo.org/wiki/Project:Portage) activity. See individual workspace crates
for details:

* [emlop](emlop) is the end-user binary
* [emlop-lib](emlop-lib) implements core functionality and can be used in other projects
